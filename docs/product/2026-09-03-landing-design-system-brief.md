## 0. Зачем: аудит того, что уже лежит в GitHub

Полной дизайн-системы в репозитории **нет**. Есть три несогласованных источника:

| Источник | Что это | Проблема |
|----------|---------|----------|
| `DESIGN.md` (245 строк, EN) | Стиль «Apple Light»: `#ffffff`/`#f5f5f7`, текст `#1d1d1f`/`#86868b`, акцент `#0071e3`, Manrope 500–600 + Inter, пилюли-кнопки | Единственный документ, который совпадает с живым кодом лендинга. Но это описание тона, а не система: нет токенов, нет состояний, нет спецификаций компонентов |
| `BRAND_CODE.md` (1484 строки, RU, «v1.0 · апрель 2025») | ТЗ для дизайнера в Figma | Описывает **другую** систему: primary `#2563EB` (Tailwind blue-600), нейтрали zinc, заголовки Bold 700, JetBrains Mono, радиусы `rounded-lg`. Противоречит `DESIGN.md` и лендингу. Figma-файл по нему так и не появился |
| `src/app/globals.css` | Реальные токены | Всего 6 CSS-переменных (`--background`, `--foreground`, `--secondary`, `--surface`, `--accent`, `--border`). Компоненты лендинга их не используют, а хардкодят hex прямо в className |

Что показал прогон по коду лендинга (`landing-delovoy-park.ru/components/*.tsx`):

- **Хардкод вместо токенов.** `text-[#1d1d1f]` встречается 40+ раз, `bg-[#f5f5f7]` 17 раз, `text-[#86868b]` 25 раз. Ни один компонент не ссылается на `var(--accent)` и т. п.
- **Разъехавшиеся оттенки.** Hover-серый то `#ebebed`, то `#e5e5e7`; вторичный текст то `#86868b`, то `#3d3d3f`; в navbar смешаны `text-white/50|60|70|80`.
- **Незадокументированные цвета.** `#FC3F1D` и `#FBC02D` (Яндекс, звёзды рейтинга), `#25D366` (WhatsApp), `#229ED9` (Telegram), `#7C3AED` и `#16A34A` (акценты модулей в карточках услуг). Нигде в `DESIGN.md` их нет.
- **Мёртвый тёмный hero.** `hero-section.tsx` — старый вариант на `bg-black` с `#0099ff`, никуда не импортируется. В проде `hero-section-with-video.tsx`.
- **Общие примитивы живут в другой системе.** `src/components/ui/button.tsx` — `bg-blue-600 rounded-lg`, `badge.tsx` — `bg-blue-100/green-100/...`. Это система из `BRAND_CODE.md`, не лендинга. Один и тот же «primary» на сайте выглядит по-разному в зависимости от того, кто писал компонент.
- **Нет:** JSON токенов, спецификации состояний (hover/focus/active/disabled/loading), тёмной темы для публичных страниц, правил для фото (в `public/media` лежат HDR-фото парка без правил обработки), правил иконографии, motion-гайда (есть только `fade-in-section.tsx`).

**Вывод:** нужна не «дорисовка», а пересборка: взять живую систему «Apple Light» из `DESIGN.md` как базу (она уже в проде и нравится владельцу), формализовать её в токены, закрыть дыры и списать `BRAND_CODE.md` в архив.

## 1. Цель и результат

**Цель.** Одна дизайн-система лендинга: токены → примитивы → секции → страницы. Всё, что на лендинге, собирается из неё без хардкода.

**Результат от Claude Design** (в порядке приоритета):

1. Канвас с артбордами (см. §6) — визуальный источник правды.
2. `design-tokens.json` в формате W3C Design Tokens (см. §3.6) — импортируется в `globals.css` через `@theme`.
3. Обновлённый `DESIGN.md` (RU + EN) — заменяет текущий, ссылается на токены по именам, а не на hex.
4. Список изменений против текущего лендинга: что оставить, что переделать, почему.

Не результат: Figma-файл, логотип, брендбук для печати, редизайн админки и Mini App.

## 2. Бренд и ограничения

- **Продукт.** Бизнес-парк в Селятино (МО, 30 км от Москвы): аренда офисов от 15 м², Барбекю Парк (беседки с мангалом), Плей Парк (PlayStation), кафе с доставкой, парковка. 300+ отзывов ★ 5.0 на Яндекс Картах — главный аргумент доверия.
- **Аудитория.** B2B: предприниматели МО, ищущие офис. B2C: сотрудники парка, местные жители, семьи с детьми. Мобильный трафик из РФ преобладает (мобильные операторы, CGNAT) — производительность и вес страницы критичны.
- **Характер.** Надёжно · Просто · Рядом · По делу · Современно. Деловой, но не холодный. Без канцелярита.
- **Сохранить обязательно** (проверено в проде, менять только с обоснованием):
  - светлая тема как основная, белый `#ffffff` + `#f5f5f7` чередованием секций;
  - пара шрифтов Manrope (заголовки, 500–600) + Inter (текст) — файлы уже self-hosted в `src/app/fonts/` (400–700, latin + cyrillic), другие шрифты не добавлять;
  - синий акцент `#0071e3` только на интерактивных элементах;
  - пилюли-кнопки `rounded-full` для CTA;
  - видео-фон hero с постером на мобильных (ADR `landing-delovoy-park.ru/docs/2026-04-09-mega-landing-adr.md`).
- **Запрещено.** Тёмные фоны для контентных секций, градиенты как декор, glassmorphism, цветные тени, serif, weight 700+ в заголовках, новые шрифты, новые акцентные цвета вне списка §3.2.

## 3. Требования к токенам

### 3.1 Нейтрали и поверхности

Закрепить шкалу, чтобы убрать разъехавшиеся `#ebebed`/`#e5e5e7`/`#3d3d3f`:

| Токен | Значение (стартовое) | Роль |
|-------|----------------------|------|
| `color.surface.0` | `#ffffff` | страница, карточки |
| `color.surface.1` | `#f5f5f7` | чередующиеся секции, серые карточки |
| `color.surface.2` | один из `#ebebed`/`#e5e5e7` — выбрать и обосновать | hover серых карточек, чипсы |
| `color.text.primary` | `#1d1d1f` | заголовки, основной текст |
| `color.text.secondary` | `#86868b` | описания |
| `color.text.tertiary` | `#86868b` @ 60% → дать непрозрачный эквивалент | подписи, плейсхолдеры |
| `color.border.subtle / default / strong` | `black/4%`, `black/8%`, `black/12%` | разделители, инпуты, hover |

Проверить контраст `#86868b` на `#f5f5f7` (сейчас ≈ 3.2:1 — не проходит AA для мелкого текста). Предложить либо более тёмный secondary для текста ≤14px, либо правило «secondary только ≥15px».

### 3.2 Акценты

| Токен | Значение | Где |
|-------|----------|-----|
| `color.accent.default / hover / active` | `#0071e3` / `#0077ED` / определить | кнопки, ссылки, фокус |
| `color.accent.subtle` | определить (тинт ≈ 8–10%) | фон иконок преимуществ, выделения |
| `color.module.rental / gazebos / psPark / cafe / parking` | сейчас в коде `#0071e3`, `#16A34A`, `#7C3AED`, ? , ? | акцент карточек услуг; дать всем пяти модулям цвет и обосновать |
| `color.rating` | `#FBC02D` (звёзды) | секция отзывов, бейдж в hero |
| `color.brand.yandex / telegram / whatsapp` | `#FC3F1D` / `#229ED9` / `#25D366` | только в кнопках/логотипах партнёров, никогда как UI-акцент |
| `color.status.success / warning / danger` | определить, согласовать с админкой (`green-600`, `amber-600`, `red-600`) | формы, тосты |

### 3.3 Типографика

Взять шкалу из `DESIGN.md` §3 как базу, дописать **мобильные значения** для каждой ступени (сейчас только `clamp()` у hero) и правила переносов кириллицы (длинные слова: «Барбекю Парк», «бронирование», `hyphens: manual` + `&shy;`).

Обязательные ступени: `display.hero`, `display.section`, `heading.lg/md/sm`, `body.lg/md/sm`, `caption`, `label`, `button`. Для каждой: font, size (desktop/mobile), weight, line-height, letter-spacing.

### 3.4 Отступы, сетка, радиусы, тени

- Base 4px, шкала как в `DESIGN.md` §5. Секции: 96–120px desktop / 56–64px mobile — зафиксировать одно значение на секцию, а не диапазон.
- Контейнер 1200px, gutter 24px desktop / 16px mobile. Брейкпоинты Tailwind по умолчанию (`sm 640 / md 768 / lg 1024 / xl 1280`) — не придумывать свои.
- Радиусы: `sm 8 / md 12 / lg 16 / xl 24 / full`. Убрать разнобой `rounded-lg` vs `rounded-xl` в одинаковых по смыслу элементах.
- Тени: три уровня (`sm/md/lg`), нейтральные, без цвета. Дать точные значения.

### 3.5 Motion

- Один easing и две длительности (`fast 150ms`, `base 250ms`) для hover/фокуса.
- Появление секций при скролле (существующий `fade-in-section.tsx`): задать параметры (смещение, длительность, threshold) и обязательный `prefers-reduced-motion`.
- Hero-видео: правила постера, затемняющего слоя (`bg-white/60` сейчас) и контраст текста поверх видео (минимум 4.5:1 на любом кадре — проверить на реальных кадрах из `public/media`).

### 3.6 Формат токенов

W3C Design Tokens (`$value`, `$type`), одна тема `light`. Имена в kebab/dot, без hex в именах. Пример:

```json
{
  "color": {
    "surface": { "0": { "$value": "#ffffff", "$type": "color" } },
    "accent": { "default": { "$value": "#0071e3", "$type": "color" } }
  }
}
```

Из него разработчик сгенерирует `@theme` в `globals.css` (Tailwind v4) и утилиты вида `bg-surface-1`, `text-text-secondary`, `bg-accent`.

## 4. Требования к компонентам

Для каждого — все состояния: default / hover / focus-visible / active / disabled, где применимо loading и error. Мобильный и десктопный вариант. Минимальный touch-target 44px.

**Примитивы (`src/components/ui/`, шарятся с публичными страницами модулей):**

1. Button: `primary` (синяя пилюля), `secondary` (серая пилюля `#1d1d1f/6%`), `ghost`, `danger`; размеры `sm/md/lg`; с иконкой; full-width на мобильных. **Сейчас** `button.tsx` — `bg-blue-600 rounded-lg`, надо привести к системе лендинга и сказать, как это не сломать в админке (варианты: пропс `appearance`, либо отдельный `PublicButton`).
2. Input / Textarea / Select (нативные), label, helper, error. Стартовая точка: `waitlist-form.tsx`.
3. Card: белая на сером, серая на белом, с рамкой; интерактивная (hover-подъём как в `services-section.tsx`).
4. Badge / Chip: рейтинг-бейдж hero, модульные чипсы, статус.
5. Link: inline, с иконкой стрелки, nav-link.
6. Toast (есть `toast.tsx`), Bottom sheet (есть `bottom-sheet.tsx`) — только визуальные правила.

**Секции лендинга (`landing-delovoy-park.ru/components/`):**

| Секция | Файл | Что решить |
|--------|------|-----------|
| Navbar | `navbar.tsx` | Прозрачная поверх видео → белая при скролле; мобильное меню; убрать смесь `text-white/50…80` |
| Hero с видео | `hero-section-with-video.tsx` | Контраст текста, постер, бейдж «300+ отзывов», две CTA, ряд статистики |

## 7. Критерии приёмки

- [ ] Ни одного hex в спецификациях компонентов — только имена токенов.
- [ ] Все цветовые пары текст/фон проходят WCAG AA (4.5:1 для текста <18px, 3:1 для крупного и UI).
- [ ] Каждый компонент имеет состояния default/hover/focus-visible/disabled; интерактивные — active.
- [ ] Touch-target ≥44px, CTA на мобильных full-width.
- [ ] `prefers-reduced-motion` учтён во всём motion.
- [ ] Модульные акценты заданы всем 5 модулям и не конфликтуют с `color.accent`.
- [ ] Шрифты только Manrope + Inter, weights 400–600 для текста, ≤600 для заголовков.
- [ ] Токены валидны как W3C Design Tokens JSON.
- [ ] Список изменений против текущего лендинга содержит обоснование каждого визуального отхода от прод-версии.
