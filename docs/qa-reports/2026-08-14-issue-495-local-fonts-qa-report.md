**Issue**: https://github.com/aylisrg/Platform-Delovoy/issues/495
**Ветка**: `claude/issue-495-local-fonts`, коммит `cf23c56`
**Ревью кода**: PASS (code-reviewer); файл отчёта ревьюера в `docs/qa-reports/` не найден — сверялся по описанию задачи и независимо перепроверил все его выводы сам.

## Скоуп

`next/font/google` → `next/font/local` в `src/app/layout.tsx` и `src/app/webapp/layout.tsx`; локальные WOFF2 (Manrope/Inter, 400/500/600/700, latin+cyrillic) в `src/app/fonts/`; CSP в `next.config.ts` очищен от `fonts.googleapis.com`/`fonts.gstatic.com`; регрессионный тест `src/app/__tests__/fonts.test.ts`.

## Критерий готовности (3 части) — независимая проверка

### 1. `npm run build` не делает сетевых запросов за шрифтами

Docker-демон в песочнице недоступен (`docker info` — нет `/var/run/docker.sock`, не systemd-init, `dockerd`-бинарник есть, но поднять негде). Вместо этого добился **реальной, а не имитированной** сетевой изоляции через Linux network namespace (`unshare -n`, root в песочнице), что закрывает главный пробел ревью кода:

- Подтвердил, что изоляция настоящая: внутри `unshare -n` даже прокси-сокет хоста (`127.0.0.1:46025`, через который здесь идёт весь внешний HTTPS) недостижим — у namespace свой независимый loopback-стек. Т.е. подмена `NO_PROXY`/hosts тут ни при чём, сеть отрезана на уровне ядра.
- Сравнительный тест: собрал `main` (до фикса, `next/font/google`) в отдельном git worktree под той же изоляцией → сборка **падает** с той же ошибкой, что и в реальном инциденте 12.08 (буквально тот же хэш `manrope_b60da44d.module.css`, что в логе из issue). Это доказывает, что техника изоляции не «пустая» — она действительно ловит сетевую зависимость.
- Затем собрал текущий HEAD (после фикса) в той же изоляции: `✓ Compiled successfully in 42s`, `Build error occurred` не встречается, в `.next/static/media/` появились ровно 8 ожидаемых `.woff2` (inter/manrope × 400/500/600/700).
- (Побочная находка при первой попытке: сборка HEAD падала с внутренней ошибкой Turbopack `node process exited before we could connect to it` — это артефакт того, что я по неосторожности убил и loopback у Turbopack-воркеров, а не сетевая зависимость от шрифтов; поднял `lo` внутри namespace через маленький C-хелпер (ioctl `SIOCSIFFLAGS`), внешняя сеть при этом остаётся отрезанной — прокси хоста по-прежнему недостижим, роут наружу отсутствует.)
- Grep по `.next/**` на `fonts.googleapis.com`/`fonts.gstatic.com` — 11 совпадений, все — строка `webfonts.googleapis.com` внутри библиотеки `googleapis`/`@vercel/og` (несвязанный сторонний Google API client, а не `next/font/google`); ложное срабатывание по подстроке, не риск.
- Grep по `src/` на `next/font/google` — только 3 файла: сам тест-регрессии и два комментария-упоминания в layout'ах (не импорт, см. п.3).

**Вывод**: критерий выполнен, подтверждено реальной сборкой под сетевой изоляцией, не только статическим анализом. PASS.

### 2. Сборка воспроизводима при недоступном Google Fonts

Показано выше тем же экспериментом — сборка HEAD успешна именно в условиях полной недоступности Google (не таймаут/деградация, а тот же отказ, что уронил прод 12.08, только теперь не воспроизводится). PASS.

### 3. Внешний вид страниц не изменился

- `git show main:src/app/layout.tsx` vs HEAD: `variable: "--font-manrope"` / `"--font-inter"`, `weight: ["400","500","600","700"]`, `display: "swap"` — идентичны до/после.
- `git show main:src/app/webapp/layout.tsx` vs HEAD: `variable: "--font-inter"`, `display: "swap"` — идентичны. Единственная содержательная разница: раньше `Inter` без явного `weight` (вариативный шрифт Google, диапазон 100–900 непрерывно), теперь фиксированные начертания 400/500/600/700. Проверил отдельно — во всём `src/` нет ни одного использования `font-extrabold`/`font-black`/`font-thin`/`font-light` или произвольных `font-[weight]` вне 400–700 (grep пустой), то есть теоретический риск (не тот вес шрифта, synthetic bold) на практике нигде не задействован.
- CSS-переменные не «зависли»: `src/app/globals.css` — `--font-display: var(--font-manrope)`, `--font-sans: var(--font-inter)` (Tailwind v4 CSS-first, `tailwind.config.*` в проекте нет), `body { font-family: var(--font-inter), ... }`; `webapp.css` аналогично на `--font-inter`. Имена переменных не менялись → нет риска fallback-шрифта.

**Вывод**: PASS.
