## F1 — PS Park: запрет завершения сессии без оплаты

> **Файлы:** `src/modules/ps-park/service.ts`, `session-bill-modal.tsx`, `complete-session-button.tsx`, `api/ps-park/bookings/[id]/route.ts`, `lib/api-response.ts`

### F1.1 — Базовый запрет (cash=0, card=0)

1. Открой `/admin/ps-park`
2. На любом столе выбери активную сессию (CONFIRMED или CHECKED_IN) с totalBill > 0 (например 300 ₽ за час). Если нет — создай через UI.
3. Нажми «Завершить» → откроется modal со счётом
4. Обнули поле «Наличные» в `0` и «Безналичные» в `0`
5. Нажми «Завершить сессию»

**Ожидается:**
- [ ] Кнопка `disabled` (UI-уровень) — клик не проходит, или
- [ ] Если кликнулось — модалка **остаётся открытой**, появляется красная inline-ошибка «Необходимо принять оплату: не хватает X ₽»
- [ ] В Network: `PATCH /api/ps-park/bookings/{id}` → **HTTP 422** с `error.code = "PAYMENT_REQUIRED"`, `error.metadata.shortfall = X`
- [ ] Сессия **НЕ закрылась** — в списке активных всё ещё видна
