## AC3 — консервативность (false negative safer than false positive)

**Проверил распространённый паттерн, который эвристика пропускает** —
"Тест 1" / "test 1" / "тест 2" (нумерованные тестовые попытки — очень
типичный паттерн, когда человек проверяет форму фидбека несколько раз
подряд):

```
isLikelyTestFeedback('Тест 1')  === false   // НЕ фильтруется
isLikelyTestFeedback('test 1')  === false   // НЕ фильтруется
```

Причина: "1" как отдельное слово (после пробела) не матчит `TEST_WORD_RE`
(нужен префикс тест/test/провер на этом же токене) и не входит в noise-лист,
поэтому `meaningful` содержит непокрытое слово → не фильтруется. Это —
**реальный, но некритичный gap**: по духу issue («ложноотрицательный
безопаснее ложноположительного») это ожидаемое поведение узкой эвристики, не
регресс и не блокер, но стоит зафиксировать для следующей итерации фильтра.
Слитные варианты той же идеи ловятся: `isLikelyTestFeedback('тест2') === true`.

**Целенаправленно искал false positive** (короткий реалистичный баг,
ошибочно отфильтрованный) — не нашёл ни одного тревожного случая на
реалистичных формулировках:

```
'Проверка платежа зависла'                      -> false (не фильтруется)
'Не работает проверка QR-кода на входе'         -> false
'Тестовая версия сайта не открывается'          -> false
'Тестировал бронь — деньги списались, слот не создался' -> false
'тестовый заказ не проходит'                    -> false
'test order failed'                             -> false
```

Единственная зона неопределённости — голое одно слово без контекста,
`'Проверка'` / `'проверка'` → `true` (фильтруется). Технически это может
теоретически быть чей-то предельно лаконичный баг-репорт («[функция]
проверки не работает»), но на практике голое одно слово без единого
дополнительного слова функционально неотличимо от человека, тестирующего
саму форму фидбека (тот же паттерн, что и реальный #486 «Тестирую обратную
связь» — тоже про саму форму, просто чуть длиннее). Не считаю это багом:
консервативность здесь всё ещё в разумных пределах, а не поломкой AC.

API endpoint, без RBAC-поверхности, без пользовательского ввода, идущего в
