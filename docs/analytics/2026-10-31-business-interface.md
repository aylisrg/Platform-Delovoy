# Интерфейс бизнес-аналитики

Реализован по ТЗ после независимой оценки источников. Страница `/admin/analytics/business`, мобильная версия `/webapp/business-analytics`.

## Визуальные решения

- Спокойный белый фон, zinc-текст, emerald-акцент. Карточка нетто выделена тёмно-зелёным; возвраты показаны отдельно. Одновременно видны абсолютные значения и изменение к равному предыдущему периоду.
- SVG-график ежедневных поступлений, корректировок, возвратов и нетто; поддерживает отрицательное нетто. Наведение и клавиатурный фокус раскрывают точные значения; доступна таблица.
- Три самостоятельные карточки направлений. Денежный результат отделён от количества операций и клиентов. Ограничения покрытия показаны постоянно, без наведения.
- Офисы отмечены исключёнными; парковка и сауна недоступны. Отсутствие источника, частичное покрытие, реальный ноль и ошибка загрузки имеют разные состояния.
- Воронки не изображают ложную когортную конверсию. У каждого шага указана единица; события онлайн-оплаты подписаны как частичный сигнал.
- Печатный визуальный отчёт и CSV доступны из защищённой админки. Никакие публичные изображения, финансовые localStorage-копии или ссылки-ключи не создаются.
- Личная подписка Telegram имеет явный статус, расписание, тест и журнал последней доставки. Положительный результат выводится только после подтверждения сервера. Неопределённый исход блокирует немедленное повторение; потерянный сетевой ответ проверяется с тем же requestId.

## Доступ и точная неделя

Серверная страница проверяет текущий доступ до рендера оболочки. При входе сохраняются только валидные period/weekEnding. Mini App использует свой авторизованный apiFetch; ссылки в настройках видны ADMIN с analytics и SUPERADMIN. Сервер API остаётся основным барьером.

## Проверки дизайнера

13 unit/UI-проверок: отсутствующие данные и отрицательные суммы; точная неделя; снятие старых цифр при отказе; неуспешное сохранение переключателя; дедупликация теста/неопределённая доставка; Mini App transport; anonymous/revoked/fresh page access; безопасное сохранение query через вход. ESLint: ошибок нет, предупреждения только о принятом в репозитории загрузочном useEffect-паттерне. Проверка TypeScript не выявила ошибок в UI-файлах.

Браузерные скриншоты desktop/mobile и окончательное визуальное QA переданы отдельному QA-агенту: Chromium в исходном окружении отсутствовал. Реальные финансовые данные для дизайн-проверок не использовались.
