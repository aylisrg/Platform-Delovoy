# Claude Code Agent

Telegram-бот, который принимает задачи от владельца и выполняет их через [Claude Code CLI](https://github.com/anthropics/claude-code) в изолированном рабочем репозитории.

---

## Как это работает

```
Telegram → Grammy Bot → TaskQueue → claude --print → Telegram
                          (FIFO)      (в /workspace)
```

### Полная схема

```
┌─────────────────────────────────────────────────────────┐
│  Telegram                                               │
│                                                         │
│  Пользователь ──▶ "создай ветку feature/x и напиши..." │
└───────────────────────────┬─────────────────────────────┘
                            │ HTTPS polling
                            ▼
┌─────────────────────────────────────────────────────────┐
│  Docker контейнер (Hetzner VPS, Германия)               │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │  Grammy Bot                                     │   │
│  │                                                 │   │
│  │  1. Whitelist — только AGENT_TELEGRAM_USER_ID   │   │
│  │  2. Принимает текст → кладёт в очередь          │   │
│  │  3. Отвечает "Принято, выполняю..."             │   │
│  └──────────────────────┬──────────────────────────┘   │
│                         │                               │
│  ┌──────────────────────▼──────────────────────────┐   │
│  │  TaskQueue (FIFO)                               │   │
│  │                                                 │   │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐      │   │
│  │  │ задача 1 │→ │ задача 2 │→ │ задача 3 │      │   │
│  │  │  (active)│  │(waiting) │  │(waiting) │      │   │
│  │  └──────────┘  └──────────┘  └──────────┘      │   │
│  │                                                 │   │
│  │  Одна задача за раз. Следующие ждут.            │   │
│  └──────────────────────┬──────────────────────────┘   │
│                         │                               │
│  ┌──────────────────────▼──────────────────────────┐   │
│  │  Claude Runner                                  │   │
│  │                                                 │   │
│  │  spawn("claude", ["--print", task])             │   │
│  │    cwd: /workspace  (git clone репо)            │   │
│  │    timeout: 15 мин                              │   │
│  │                                                 │   │
│  │  stdout → чанки по 4000 символов → TG          │   │
│  │  прогресс-пинг каждые 30 сек                   │   │
│  └──────────────────────┬──────────────────────────┘   │
│                         │                               │
│  ┌──────────────────────▼──────────────────────────┐   │
│  │  Claude Code CLI  (v2.x)                        │   │
│  │                                                 │   │
│  │  OAuth токен ──▶ volume claude_auth:/root/.claude│  │
│  │  Workspace    ──▶ /workspace (git clone)        │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                            │
                            │ stdout chunks
                            ▼
┌─────────────────────────────────────────────────────────┐
│  Telegram                                               │
│                                                         │
│  Бот ──▶ "Ветка feature/x создана. Вот что сделал:..." │
└─────────────────────────────────────────────────────────┘
```

## Компоненты

| Файл | Роль |
|------|------|
| `index.ts` | Grammy bot: whitelist, команды `/start` `/status` `/tasks` `/cancel` `/new`, роутинг в очередь |
| `lib/queue.ts` | FIFO очередь — одна задача за раз, остальные ждут |
| `lib/store.ts` | Персистентное хранилище задач + session continuity (JSON в `/workspace/.agent-state.json`) |
| `lib/claude-runner.ts` | Запускает Claude Code с project context, git-sync перед каждой задачей, timeout 30 мин |
| `Dockerfile` | `node:20-bookworm-slim` + git + `@anthropic-ai/claude-code` |

```
│  └── .env  (секреты)                        │
│                                             │
│  /opt/claude-agent-workspace/               │
│  └── git clone репо (рабочий workspace)     │
│                                             │
│  Docker volumes:                            │
│  ├── claude_auth   → /root/.claude  (OAuth) │
│  └── workspace     → /workspace             │
└─────────────────────────────────────────────┘
```

Сервер находится в **Германии** — это принципиально: OAuth Anthropic не работает с российских IP-адресов.

## Безопасность

- **Whitelist** — бот игнорирует все сообщения, кроме `from.id === AGENT_TELEGRAM_USER_ID`
- **Изоляция** — контейнер не имеет доступа к prod БД и Redis
- **Memory limit** — 1 GB RAM, нет открытых портов наружу
- **OAuth персистентность** — токен в Docker volume, переживает перезапуски и деплои

## Команды

| Команда | Действие |
|---------|----------|
| любой текст | Выполнить как задачу через Claude Code |
| `/start` | Приветствие и инструкция |
| `/status` | Состояние очереди |
| `/tasks` | Последние 10 задач со статусами и ветками |
| `/cancel` | Остановить текущую задачу |
| `/new` | Сбросить контекст сессии (начать новый разговор с нуля) |

## Первичная настройка (one-time)

После деплоя на Hetzner нужно один раз залогиниться:

```bash
ssh root@<HETZNER_IP>
docker exec -it delovoy-agent bash -c 'COLUMNS=9999 claude auth login'
# Открыть URL в браузере → авторизоваться → токен сохранится в volume
```

После этого перезапуск контейнера авторизацию не сбрасывает.
