# Дизайн-система лендинга «Деловой Парк»

Источник правды для стилей публичного лендинга (`src/app/page.tsx`,
`landing-delovoy-park.ru/components/*`, публичные примитивы `src/components/ui/*`).
Собрана по ТЗ `docs/requirements/2026-09-03-landing-design-system-brief.md`
в Claude Design, тема light. Админка и Mini App — вне области, только совместимость токенов.

Канвас с артбордами (правится визуально, Save публикует новую версию):
https://claude.ai/code/artifact/e304994a-9761-479c-b3fe-b86d3e445d34

## Что здесь

| Путь | Что это |
|------|---------|
| `tokens.json` | Токены в формате W3C Design Tokens (`$type`/`$value`). Мобильные значения — в `$extensions["delovoy.mobile"]`. Из него генерируется `@theme` в `src/app/globals.css` (Tailwind v4) |
| `canvas/Main.dc.html` | Лендинг, desktop 1440 |
| `canvas/Mobile.dc.html` | Лендинг, mobile 390 |
| `canvas/Foundations.dc.html` | Лист токенов: цвет, типографика, отступы, радиусы, тени, motion |
| `canvas/Components.dc.html` | Компоненты во всех состояниях: кнопки, инпуты, карточки, бейджи, чипы, навбар, ссылки, тост, empty state |
| `canvas/canvas.json` | Раскладка артбордов и заметки с обоснованием изменений |
| `canvas/*.jpg` | Фото парка из `public/media`, сжатые для канваса (≤48 КБ) |
| `previews/*.jpg` | Рендеры артбордов для просмотра без канваса |

Артборды — самодостаточные HTML-файлы с инлайн-стилями: их можно открыть в браузере
как есть (шрифты подтянутся с Google Fonts, в проде используются те же Manrope и Inter
из `src/app/fonts/`).

## Ключевые решения (против прода на 2026-09-03)

- **`text.secondary` = `#6e6e73`** вместо `#86868b`: на `surface.1` контраст был 3.2:1, стал 4.7:1 (AA).
  `#86868b` остаётся `text.tertiary` только для текста от 15px и декоративных подписей.
- **Один hover-серый** `surface.2` = `#e8e8ed` вместо `#ebebed` / `#e5e5e7` в коде.
- **Модульные цвета** закреплены за всеми пятью модулями: офисы `#0071e3`, Барбекю Парк `#16a34a`,
  Плей Парк `#7c3aed`, кафе `#ea580c`, автостоянка `#0891b2`. Живут только внутри карточки своего
  модуля, `accent` в навигации, формах и ссылках не заменяют.
- **Партнёры и статусы** вынесены в именованные токены (`brand.yandex`, `brand.twoGis`, `brand.telegram`,
  `brand.whatsapp`, `status.warning` для бейджа «Сдан»).
- **Типографика**: та же пара Manrope 600 + Inter 400/500, каждая ступень получила мобильное значение;
  weight 700 не используется.
- **Motion**: один easing `cubic-bezier(0.2, 0.8, 0.2, 1)`, `fast` 150ms / `base` 250ms,
  reveal при скролле 500ms, `prefers-reduced-motion` → только opacity.

## Как обновлять

1. Правки дизайна — на канвасе по ссылке выше (Save) или в `canvas/*.dc.html`.
2. Изменил значение токена — обнови `tokens.json` и артборд `Foundations` в одном коммите.
3. Внедрение в код — одним PR по разделу 8 ТЗ: `globals.css` из токенов, примитивы `src/components/ui`,
   замена хардкода hex в компонентах лендинга, снапшот-тесты и e2e-скрины на 1440 и 390.
